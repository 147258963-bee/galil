Este repositorio contiene el núcleo del Sistema Operativo para miras inteligentes integradas en el fusil **IWI Galil ACE 22**. El software utiliza visión computarizada avanzada para mejorar la conciencia situacional y la precisión del operador.

---

## ✨ Características Principales

* 🧠 **Detección de Objetivos en Tiempo Real:** Identificación automática de amenazas mediante el modelo YOLOv8.
* 🌡️ **Visión Térmica Digital:** Algoritmo de mapeo de calor para operaciones de baja visibilidad.
* 🔫 **Smart Telemetry:** Contador de munición dinámico y estado del hardware.
* 🔐 **Auto-Licensing:** Sistema integrado de registro de hardware y protección de propiedad intelectual.
